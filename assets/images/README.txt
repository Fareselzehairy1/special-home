# مجلد صور الموقع — Special Home

يُفضّل استخدام صور بصيغة WebP وعرضها بـ lazy loading كما هو مطبّق حاليًا في الصفحات.

البنية المقترحة:
- hero/        صور البانر الرئيسي (2400×1400)
- projects/    صور المشاريع (1600×1000)
- gallery/     صور معرض المشروع (1600×1200)
- team/        صور الفريق (800×800)
- blog/        صور المقالات (1200×750)

ملاحظة: الموقع حاليًا يعرض صور Unsplash المؤقتة عبر الروابط الخارجية.
استبدل كل رابط بصورتك المحلية مثل: assets/projects/cairo-view-01.webp
